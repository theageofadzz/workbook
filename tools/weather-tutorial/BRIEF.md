## Intent

用户要求文章各节增加动画解析，展示具体怎么做，并显示鼠标。
沿用现有文章的清淡纸面、蓝色和黄色，不添加音乐或配音。
演示为基于实际素材和代码的操作示意，不标记成历史录屏。
继续完成网站编辑、验证与已授权的 GitHub 同步。

## Assets

- 已实现的 HTML 中的七层图集、48 帧位置数据。
- 原始参考截图与最终 weather 图像。
- 网站正在使用的 cicada 鼠标图标。

## Decisions

采用六段无声、无播放按钮的动画，分别嵌入六个小节。
短句说明留在动画下方；可见时播放，离开视野时暂停。
以上时长和制作形式由现有文章结构决定。
