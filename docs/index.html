Intensea Logo 的设计思路

intensea 是 intense 和 sea 的结合。紧绷与蔚蓝大海，都是我的一部分。

为什么叫theageofadzz？

这个名字源自我特别喜欢的一个专辑 theageofadz，这也是为什么我网站顶部叫 “奥兹时代”，多打了一个z是为了区分。

独特的icon艺术风格

我相信你进入我的网站最被吸引的是我的底部导航栏设计，除了作为我身份标识的intensea的logo是我原创的以外，其他的都是我在网上找到的icon。

那么cicada是谁？

这是我在github的昵称，致敬我最喜欢的华语歌曲《蝉想》，因此我的头像也是一只夏蝉
