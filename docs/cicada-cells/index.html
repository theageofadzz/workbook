让细胞在网页里呼吸

从一段三维动效出发，把细胞的呼吸、生长和消失，做成可以亲手改变的网页。

在 X 上看到 Second Eight 分享的「Tessel in 3D」，第一眼吸引我的，是那一团暗色物体的质感。它们挤在一起，边缘透出一点暖光，表面缓慢起伏。背景从黑色过渡到灰粉色，画面里几乎没有多余的东西。

我把链接发给 Codex，先提了一个很直接的要求：复刻这个效果，用 HTML 给我。和上一次做蓝图交互时一样，起点是一张想留住的画面，后面的调整才慢慢决定它会成为怎样的网页。

先让它看起来是软的

这个效果很容易做成几颗发亮的球。球体、反光和渐变背景都齐了，放在一起却还是硬的。真正需要处理的是它们接触的地方：两个细胞靠近时，轮廓要稍微压平，连接处要有一层薄薄的膜，大小也不能完全相同。

我想保留参考里那种烟色玻璃般的暗，不把亮度提得太高。细胞中央沉下去，边缘留一点反射，上半部接住暖灰色的光。拖动时，反光跟着表面转，才能看出它的体积。这里用 Three.js 和着色器组织形状与光线，重点是视觉上的柔软感。

呼吸也要很轻。每个细胞用略有差别的节奏起伏，整团再慢慢摆动。如果所有东西同时放大、同时缩小，就会像一个统一缩放的模型；有一点时间差，画面才会松下来。它是一项以细胞为意象的视觉练习，画面上的名称沿用实验的表达，并不对应真实生物数据。

按一下，让它长出一个

做到可以观看后，我又加了一个要求：能不能增加或者减少细胞的数量，而且把变化过程做好？于是，页面底部多了减号、数字和加号，数量可以从 1 调到 20。

最有意思的部分在按下按钮之后。新增的细胞从相邻细胞附近小小地鼓起来，慢慢长到自己的大小；周围的细胞随之让出位置。减少时，它会向邻居靠拢，一边收缩一边消失。留在画面里的细胞再聚拢，填上刚才的空位。

位置、大小和镜头距离都跟着一起过渡。数量多了，镜头稍微退开；只剩一个时，它依然待在画面中央。这里用带阻尼的弹簧逐步追上目标状态，所以连续点几次加号，或者中途改点减号，动作可以接着当前的位置继续，不用先等上一段播放完。

从黑色过渡到灰粉色

这次配色围绕#010100、#171915和#C1A39F展开。背景上半部接近#010100，往下经过#271F1F，再慢慢透出#C1A39F。明度随着位置逐渐升高，中间没有明显的分界。细胞群悬在这段过渡里，上方的暗色留出空间，下方的暖色托住轮廓，画面也有了纵深。

细胞本身保持很深的#171915，表面朝向不同，才浮出偏红的#594440和一点#171915。大部分颜色都收在暗部里，边缘接住柔和的#84807D反光。这样，体积可以通过细微的冷暖和明暗被看见，也能保留那种烟色玻璃的朦胧感。

#C1A39F同时出现在背景和细胞表面的反射里，把主体与环境连起来。暖光只在顶部、侧面和接触的边缘轻轻铺开，亮度也控制在较低的范围。细胞呼吸或转动时，颜色随着表面角度慢慢移动；新增和消失的过程沿用同一套色调，变化主要落在形状和光线上。

文字与按钮也顺着这套配色处理。署名和标识用偏暖的#D7D1CE，细胞标签更轻，左下角的文字降低不透明度，让视线先停在中央。数量数字采用更亮一点的#F2E4DF，底下垫一层#0C09094D，方便在#C1A39F背景上读清。整幅画面的颜色保持克制，层次交给明度、透明度和少量的暖光。
