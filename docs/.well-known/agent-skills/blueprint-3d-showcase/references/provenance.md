# Examples and sources

## Design workflow

Author: theageofadzz.

The drone and Model 3 case studies, interactive examples, and the article are at:
https://theageofadzz.github.io/workbook/blueprint-design-skill/

This public skill contains written design/implementation guidance and
verification images of the Model 3 adaptation. Its relative references work
after downloading or installing the folder. It contains no machine-specific
paths, third-party renderer bundle, fonts, or model binaries.

## Original inspiration

Zsolt Kacso / Whitespace, Lathe Blueprint:
https://experiments.thisiswhitespace.com/lathe-blueprint

The original drone model source:
https://experiments.thisiswhitespace.com/standalone/lathe-blueprint/models/drone_built.glb

The experiment demonstrates the grid-cell reveal and flight interaction.
Implement the behavior in the destination project and select a model with
appropriate reuse terms; attribution alone does not establish a reuse license
for the original renderer or drone artwork.
