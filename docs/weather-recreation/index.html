像素级复刻一段天气动效

先把画面对齐

我的要求是保留原作的构图、配色、字体和手绘质感。先看雨伞的位置与大小，再看右侧面板、底部文字和图形之间的距离。

实现时固定一块 518 × 518 的画布，把画面分成纸面、衣服、雨伞、人物、色块、天气和预报七层。每层记录位置与尺寸，屏幕变大时整体缩放。原有的线条和颗粒保存在图像素材里，再由 Canvas 按顺序合成。

图形像了，动作还要像

这次反馈把重点转向了动作：伞怎样展开，图块什么时候移动，温度与云朵怎样一起变化。

成品保存了 48 帧，每帧播放 80 毫秒，3.84 秒循环一次。同一图层的帧排成一张“图集”，像一页连环画；代码按帧号取图，再放回画布。

七层共用同一个播放时间，这样伞、天气卡片和预报图形就能同步。素材全部加载后才播放，切走页面时暂停，回来后继续。

调整署名和文字

画面与动作确认后，我把复刻版底部署名改成 cicada，要求保留原来的字体风格。原作作者的署名在本文开头单独说明。

“雨”的文字最后保留四种写法：雨、rain、あめ、비。去掉重复的繁体项后，再调整基线与间距。文字写入画面素材，保持与手绘图形一致的质感。

做成自动循环的 GIF

HTML 负责分层播放，作品页面使用导出的 weather.gif。导出时按每帧 80 毫秒取图，编码为无限循环的 GIF，再检查颜色和首尾衔接。

我要求去掉进度条和多余界面，所以展示时只放一个图片元素，让 GIF 自己循环。

最后怎么检查

先把参考和复刻版放到相同尺寸，对比伞的轮廓、色块、文字位置；再正常播放，检查动作节奏与循环衔接。“像素级”是这次的对齐目标，我们没有做逐帧零误差测量。
