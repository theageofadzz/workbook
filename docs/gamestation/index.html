一次3D交互实验

尝试把实体游戏盘搬入数字世界，想让鼠标变成人的手一般与虚拟世界交互。

先逛一遍这个网站

GameStation 是我做的一次 3D 交互实验，也是一个游戏展示与攻略网站。我想保留逛实体游戏店时的感觉：先被某一张封面吸引，伸手拿起盒子，打开它，再决定要不要继续了解这个游戏。

所以，首页从一排排立起来的游戏盒开始。热门游戏方便随意看看，分类、搜索和分页方便找某一款。点开盒子，左边是光盘，右边是游戏简介，以及图文攻略、奖杯列表和相关资源。下面这段实际页面录屏，记录了从浏览、开盒到查看奖杯与攻略的过程。

我希望这里的动效能解释操作本身。悬停是把盒子稍微拿起来，点击是拿到眼前查看，打开后再进入内容。鼠标仍然是鼠标，但它做出的动作，尽量接近一只手。

3D 光盘盒是怎么做的？

这一部分用 React 管理选中的游戏和展开状态，用 JavaScript 计算指针位置与卡片坐标，再由 CSS 的 perspective、preserve-3d 和 transform 完成立体效果。盒子本身由 HTML 元素拼成，没有加载三维模型。下面把项目里的关键逻辑按步骤整理出来。

先给封面一个厚度

一张图片只有正面；光盘盒还需要背面和四条侧边。项目把盒子厚度设为 16px，正面向前移动 8px，背面向后移动 8px，四条边再各自旋转 90°。外层提供 1500px 的透视，内层保留三维空间，这些平面才会组成一个盒子。

这里的类名分别对应盒体内部的六个面。蓝色边框、PS5 顶部白条、封面原画和底部标识放在正面；侧边的颜色与内阴影补上塑料的厚度感。静止时保留一点倾斜，让人一眼就能看出它有侧面。

让倾斜和反光跟着鼠标走

指针进入卡片后，先减去卡片左上角的坐标，得到它在盒子内部的位置。再以中心为零点，把横向位移换成 rotateY，纵向位移换成方向相反的 rotateX，最大倾斜约为 20°。同时把反光层的中心放在指针所在的位置，盒子就会产生被轻轻托起的感觉。

这是卡片组件中的核心事件处理：cardRef 指向盒体，glareRef 指向覆盖在封面上的反光层，两个函数分别绑定到外层的 onMouseMove 和 onMouseLeave。指针移动时只留 0.1 秒的跟随过渡，离开后用更长的缓动回到原来的姿态；被选中的卡片会停止跟随，交给展开动画接管。

从网格里的位置飞到眼前

点击时先记录原卡片的 getBoundingClientRect()，等弹层中的封面完成布局，再读取目标矩形。两者中心点的差值决定平移距离，宽度的比值决定初始缩放。把弹层封面先放回原卡片的位置，再过渡到平移为零、缩放为一，就能衔接“拿起来”的动作。这是 FLIP 思路中先测量、再反向定位、最后播放的做法。

上面把原项目的定位算法整理成了独立函数：originRect 是点击瞬间记录的原卡片矩形，overlay 是弹层的定位外壳，onArrive 在移动完成后触发开盒。项目原本在 React 的 useLayoutEffect 中更新这组样式，并以 600 毫秒定时接续开盒；这里改用过渡结束事件衔接。两次 requestAnimationFrame 让浏览器先绘制起点，再开始过渡，避免封面直接跳到终点。

最后才是翻开盒盖

盒子到达中央之后，封面绕左侧盒脊翻转 180°。关键是 transform-origin: left center：轴心放错，封面就像在原地转身，而不是被打开。外侧封面与内侧光盘分别占据翻盖的正反面，隐藏背面后，翻转到一半也不会同时看见两层内容。

关闭时顺序反过来：先合上盒盖，再用之前保存的 dx、dy 和 scale 把弹层缩回原位，最后移除弹层、显示网格里的卡片。原项目等待 600 毫秒后开始回收，再用 500 毫秒完成归位，合盖和回收有一段重叠。网格中的封面和弹层封面共用同一个 PS5CoverUI 组件，避免放大前后突然换了一套封面。

一些不想省略的小细节

背景来自 PlayStation 三十周年页面

首页淡淡的主机、手柄与配件拼贴，来自 PlayStation 官方三十周年页面。它的存在感很轻，能让熟悉这些设备的人认出来，又不会和游戏封面争夺注意力。

背景固定在页面后方，游戏列表放在带有少量透明度和背景模糊的白色区域里。滚动时，前面的游戏盒移动，后面的拼贴保持稳定，画面就有了前后层次。蓝色留给光盘盒，白色留给导航和阅读区域，封面本身的颜色因此更容易被看见。

奖杯页延续主机里的浏览方式

进入每款游戏的奖杯列表，页面会从明亮的展架切换成深色界面。我参考并复刻了 PlayStation / PS5 奖杯界面的视觉语言：顶部是游戏封面、游戏名称和奖杯总数，下面按全部、白金、金、银、铜筛选；列表里的白色描边标记当前焦点，奖杯图标和文字保持固定的对齐关系。

鼠标移动到某一项，选中框就跟随过去；键盘上下方向键也能移动焦点，并让选中的奖杯滚动到可见区域。达成条件和攻略提示只在选中项下展开，让列表保持清楚，同时保留一点用手柄浏览菜单的节奏。

打开之后，才慢慢看内容

盒盖内侧保留了蓝色塑料的纹理，光盘上复用游戏封面，并叠加圆心、反光与缓慢旋转。另一侧像随盒附上的说明书：PS5 白条、制作方标识、浅色页底和靠近盒脊的阴影，让打开之后的画面仍然像一个完整的物件。

真正进入攻略后，页面又回到标题、章节和目录。这里不需要继续翻转或旋转，只需要方便查阅。对我来说，这次实验想留下的是从“拿起一个游戏”到“开始读它的内容”之间那一点连续的感觉。
